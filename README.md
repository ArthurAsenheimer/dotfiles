# dotfiles

Single source of truth for my personal dotfiles. The layout mirrors `$HOME` 1:1 —
applying it is a plain overlay, no symlinks, no installer:

```bash
curl -fsSL https://github.com/ArthurAsenheimer/dotfiles/tarball/master \
  | tar xz --strip-components=1 -C "$HOME" --exclude LICENSE --exclude README.md
```

`bootstrap-vps.sh` (see [bootstrap-ubuntu](https://github.com/ArthurAsenheimer/bootstrap-ubuntu),
private) runs exactly this behind an **opt-in flag** — never by default.

## Structure

- `.bashrc` / `.zshrc` — lean shells; both source every `~/.config/shell/*.sh`
- `.config/shell/` — the actual content, one topic per file: `env.sh`, `aliases.sh`,
  `functions.sh`, `keybindings.sh`. Add a file, it gets sourced — nothing else to wire up.
- `.inputrc` — readline (bash) keybindings
- `~/.shell_local` — **not in this repo.** Machine-specific glue (PATH, tool inits,
  private env vars). Generated by the bootstrap script or edited by hand; sourced last
  by both rc files. This is the only file the bootstrap script ever writes.

## Rules

- **No secrets. Ever.** This repo is public. No keys, no tokens, no `.ssh/` —
  `.ssh/config` stays out too (hostnames/IPs are half-secrets).
- Machine-specific things go to `~/.shell_local`, not here.
- Removing a file here does not remove it from machines already overlaid (tarball
  overlay doesn't delete).
